About the Problem

Sarcasm is a sophisticated form of speech where the intended meaning is the opposite of the literal words used. In real-world scenarios like social media monitoring or customer feedback analysis, failing to detect sarcasm leads to inaccurate sentiment data. This web application serves as a supplementary solution to bridge that gap.

Model Architecture & Methodology

Following the course requirements, this system integrates two distinct mathematical modeling techniques:

  • Ensemble Technique: Uses a Random Forest classifier which processes TF-IDF vectorized text through multiple decision trees.
  • Neural Network: A Long Short-Term Memory (LSTM) dense-layer based network designed to capture sequential dependencies in text.
  • Dataset: Trained using a balanced sarcasm dataset to ensure unbiased classification performance.
